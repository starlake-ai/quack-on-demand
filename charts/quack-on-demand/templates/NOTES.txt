# Port-forward the read-only REST data edge (PAT bearer only)

  kubectl --namespace {{ .Release.Namespace }} port-forward \
    svc/{{ include "qod.fullname" . }}-rest {{ .Values.service.restData.port }}:{{ .Values.service.restData.port }}

  Mint a PAT (qod auth pat create), then (replace <tenant>/<db>/<schema>/<table>):

    curl {{- if .Values.rest.tls.enabled }} -k{{- end }} -H "Authorization: Bearer <qod_pat_...>" \
      "{{ if .Values.rest.tls.enabled }}https{{ else }}http{{ end }}://localhost:{{ .Values.service.restData.port }}/api/v1/tenant/<tenant>/database/<db>/schemas/<schema>/tables/<table>/rows?limit=10"

  The edge throttles failed authentication per client and caps in-flight
  requests per user. Behind a load balancer or Ingress, set
  rest.trustedProxies: without it every client shares the LB's budget, and one
  client's bad tokens block everyone. A JSON or CSV page is buffered in the
  manager heap, in a buffer that grows by doubling: budget up to 3 x
  rest.maxConcurrentTotal x the response byte cap (3 GiB by default) on top of
  the manager's own needs. Before exposing it to the
  internet, a WAF is still recommended for volumetric and DDoS limits.
{{- end }}

# Notes

- Replicas default to 1 (Recreate rollout). Set replicaCount > 1 to enable
  active-active HA (QOD_HA_ENABLED). Replicas share the session secret the
  control plane stores unless sessionJwtSecret / existingSessionJwtSecret
  pins one. See guides/RESILIENCE.md.
- The manager calls the K8s API to create / delete pods + services in
  this namespace. RBAC scope is a Role, not a ClusterRole.
- {{- if eq .Values.metrics.sink "prometheus" }} /metrics is exposed on the rest-ui port. {{- else }} metrics sink: {{ .Values.metrics.sink }} (the /metrics endpoint is NOT exposed in cloud-push mode). {{- end }}
